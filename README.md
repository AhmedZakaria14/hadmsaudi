هذه الحزمة مستقلة ولا تحتاج إلى Node.js أو React أو أدوات بناء. لعرضها محليًا، افتح ملف `index.html` في المتصفح، أو ارفع محتويات هذا المجلد مباشرة إلى الاستضافة الثابتة.

توجد صور الموقع في المجلد `assets/`. تعمل أزرار الاتصال وواتساب ونموذج الطلب باستخدام الرقم `0502833163`.
